# linux fixes

small scripts for stuff that keeps breaking on minios xfce.

minios is a tiny debian based distro for old pcs and usb sticks. it runs xfce and fluxbox. fast and light but things like saved sessions break easy.

each folder has its own readme plus fix and check scripts.

- `window-manager/` no title bars, no borders, fix xfwm4.
- `bluetooth/` bluetooth always on at boot, keep it off.
- `wallpaper/` black wallpaper, bring xfdesktop back.

tested on minios with xfce 4.20, xfwm4 4.20.0, bluez + blueman.
